Place the Cyfer desktop installer files in this folder so the home page download buttons work:

- Cyfer-Setup.exe     (Windows installer)
- Cyfer.dmg           (macOS installer)
- Cyfer.AppImage      (Linux package)

The filenames are referenced in components/home/DesktopDownloadSection.tsx (DOWNLOADS constant).
If the real files use different names, update that constant to match.
